## About Me

I build things that work under the hood — from kernel-level mechanisms to distributed AI systems. My work lives at the intersection of performance and intelligence, where low-level systems meet modern ML-driven design.

## Projects

<table>
<tr>
<td width="50%" valign="top">

**AXIOM** — Semantic Runtime Code Intelligence

Fuses LLM embeddings of ASTs across 5 languages with live eBPF kernel traces into a GNN intent graph. Catches cascading failures before deploy. Ships with a VS Code extension and a React dashboard.

`Python` `PyTorch` `eBPF` `FastAPI` `React`

</td>
<td width="50%" valign="top">

**LOKI** — Agentic Voice Desktop Assistant

44 modules. One voice. WinRT OCR, Whisper transcription, semantic browser-history search, phishing detection, streaming TTS with barge-in, and an AES-256-GCM secrets vault. Named after its creator.

`Python` `Whisper` `FAISS` `Next.js` `WinRT`

</td>
</tr>
<tr>
<td width="50%" valign="top">

**KubeHeal** — Autonomous Kubernetes Healing

Resolves config drift and container ransomware simultaneously in under 8 seconds using a GATv2 + BiLSTM health model and a Pre-LN Transformer security model, with SHAP explanations and a 5-tier auto-remediation policy.

`PyTorch` `GNN` `Kubernetes` `ONNX` `Prometheus`

</td>
<td width="50%" valign="top">

**CadForge** — Conversational CAD over MCP

Published `loki-cad-mcp` to npm. 11 MCP tools over JSON-RPC 2.0 for real parametric CAD — solids, boolean ops, 9 templates, and export to STL / STEP / OBJ / GLTF / SVG. Hardened against untrusted LLM input.

`TypeScript` `Python` `MCP` `OpenCASCADE`
